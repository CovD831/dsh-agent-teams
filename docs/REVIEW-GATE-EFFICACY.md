## 2. Findings

### F1 — **BLOCKER**：并集模型用错 —— 两个归因面在记录级是**嵌套**，不是「不相交」

- **文件:行**：`docs/GATE-EFFICACY.md:110`（「语料里有**两个互不相交**的判据归因面」）· `:130`（「两个面在时间上不相交 ⇒ 可以把它们**并集**（不会重复计数）」）· `:149`（合计行 `186`）· `:23` / `:179`（`186 / 384 = 48.4%`）
- **问题**：t16 的模型是「两个面**并列**，故 110 + 76 = 186 可直接相加」。实测模型是「**结构化字段是新增的第二重记录，标题文本一直还在**」——**110 条 `auto.gate` 记录里，110 条（100%）标题同时带 `[id]`**。两个面是**嵌套**关系，不是并列关系。

```sh
$ # 独立复算：有 auto.gate 的记录，其 title 是否也带 [gate.id]？
records with auto.gate           = 110
...of those, ALSO have title [x] = 110          ← ★ 100% 重叠
records whose title ids != auto.gate = 0        ← 无跨面错配
```

- **为什么「186」看起来是对的**：它是**两个错误互相抵消**的产物 —— 不是加了重叠，而是 t16 的「76」本身**已经**是「扣掉重叠后的余数」（我的实测：title-only-excluding-auto.gate = **77**，t16 报 76）。于是「110 + (扣重叠后的 76)」恰好≈记录级并集。
  ⇒ 但它**在文中把这个数描述成「两个不相交面之和」**，而这与事实相反。
- **代价（可核，三处互相矛盾）**：

| 位置 | t16 的数 | 我的实测 | 差 |
|---|---|---|---|
| `:23` / `:179` 可归因总数 | **186** | **187**（记录级并集） | −1 |
| `:141` `completion.backtest` 并集 | **51** | **52** | −1 |
| `:146` `completion.r5` 并集 | **8** | **13** | **−5** |
| `:149` 合计行 | **186** | 逐 id 之和 = **200** | −14 |

  ★ 注意 `:149` 那行把「并集」写成 **186**，而它**上面 9 行逐 id 数值相加 = 194**（t16 自己的数）——**这张表内部就不自洽**。我的逐 id 之和是 200。
  ★ `r5` 差 5 的成因我已定位：**同一条记录的标题可以带多个 `[id]`**（实测 12 条记录带 >1 个），例如 `f-0292 title=[completion.r5, completion.backtest]`。t16 的计数看起来只认了「第一个」或某种单值取用。
- **必须怎么修**（三步，缺一不可）：
  1. **改模型**：把 `:110`/`:130` 的「两个**互不相交**的归因面」改为准确描述 —— 「**同一个字段演进的两代形态**：标题 `[gate.id]` 是 v1（10-07→10-08 12:08），结构化 `auto.gate` 是 v2（10-08 13:58 起）；**v2 期间标题标记仍在，故两代在记录级重叠**」。
  2. **改计数口径为「记录级并集」并给出唯一真值**：`attributable = #{r : r.auto.gate ∨ title(r) 含 [gate.id]}`。实测 **187 / 384 = 48.7%**。明确写「**不是 110+76**」（因为 76 已是余数）。
  3. **修表内不自洽**：`:138-149` 的并集表改为**逐 id 记录级并集**并给出**真实合计**。我的实测（用作核对基准）：`changed-paths 57 · backtest 52 · mutation 33 · plan-reviewed 16 · r5 13 · verify-rerun 10 · build-artifact-scope 9 · verify-command 6 · task-atomicity 4`，**逐 id 之和 = 200**（≠ 记录级 187，因为一条记录可归因到多个 id）。**必须在表下并列注明这两个数各自是什么** —— 否则就是把「一条记录可计入两条判据」这个事实藏起来。

  > ★ 这最后一点正是本队「**一个数字回答两个问题**」的形态：`186` 被同时当作「有多少条卡点可归因」（187）与「各判据拦截次数之和」（200）。**两者都对，但不能是同一个数。**
