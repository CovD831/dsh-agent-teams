## 2. F2（medium · 示例两种读法）—— ✅ 修复成立，不再有两种读法

**回源**：新示例（`:483-485`）`completion ⊘⊘⊘⊘ (4 条，0 跑 / 4 跳过 ⇒ ★未检查)` + 对照格 `dispatch ✓⊘`。

我按原文三条规则逐条机械核对：
1. 全跳过 ⇒ `evaluated===0` ⇒ 不可能有 `✓` —— 新示例 4 格全 `⊘`，无 `✓` ✅；
2. 位置级"全跳过"占整行 + 行尾括注 —— 括注在场 ✅；

混合格 `dispatch ✓⊘` 与全跳过格**符号集合不同**（含 `✓`），确实不同形 ✅。

**LF-2（low）**：B0.1 符号表 #6（`:341`）规定的字面格式是「**`⊘⊘⊘` 整行** + 行尾 `(N 条，**全部跳过**)`」—— 3 个 `⊘`、括注写"全部跳过"；而新示例画 **4 个** `⊘`、括注写"**0 跑 / 4 跳过**"。语义一致，但**规则文本与示例字面不同形**：严格照 #6 抄的实现者与照示例抄的实现者会产出两种字符串。
**修法**：#6 的格式描述改为与示例一致（`⊘`×N + "0 跑 / N 跳过"），或示例旁注明"字面以示例为准，#6 为语义描述"。二选一，不要两处各说各的。
