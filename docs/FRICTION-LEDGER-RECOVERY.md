## 3. 恢复方法（可复跑，无一处编造）

用**引号状态机**找第一份完整 JSON 的结束位置 —— ★ 不是数 `{`/`}` 的个数：

```python
def first_json_end(text):
    i, depth, in_str, esc, start = 0, 0, False, False, None
    while i < len(text):
        ch = text[i]
        if start is None:
            if ch in '{[': start=i; depth=1; in_str=False; esc=False
            i+=1; continue
        if in_str:                       # ★ 字符串里的括号不算
            if esc: esc=False
            elif ch=='\\': esc=True
            elif ch=='"': in_str=False
        else:
            if ch=='"': in_str=True
            elif ch in '{[': depth+=1
            elif ch in '}]':
                depth-=1
                if depth==0: return i+1
        i+=1
    return None
```

**步骤**：① 定位第一份 JSON 的结束字节；② `json.loads(前段)` **先验证再写**；
③ 写回**只留前段**（★ **不加换行** —— 前段原本止于 `}`，而它后面紧跟第二段的 `\n`）。

★ **实测 12/12 的前段都是完整合法 JSON** ⇒ **没有任何一个需要报"前段也不完整"**。
