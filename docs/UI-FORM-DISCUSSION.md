## 2. ★★ 所以"形态"要先回答一个比布局更前的问题

```

   ⇒ ★★ 后果:collection/evaluation 造完了,而界面看不见（实测 0 次）

选项 ② ★★ 按【模块投影】组织（你早先裁定的「前端只做各模块的投影」）
   · 每个模块交一份 UiProjection（id/title/layer/readings）
   · ★ 界面按 layer 渲染,且【清单从主机来】
   ⇒ ★★★ 后果:加一个层 ⇒ ★ 后端交一份投影,界面自动出现
```

⇒ ★★ **选项 ② 是"能长出东西"的形态,选项 ① 是"每加一样就手写一遍"。**
