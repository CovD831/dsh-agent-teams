## 5. ★★ 而"吞掉未来真失败"这个危害是**真的**,而机制如下

```
★ pin 清单的用途:让"已知的存量红"不阻塞净变化判定
★★ 而它的代价:一条 pin 会【吞掉同名的真失败】
⇒ ★★ 而 17 条全是"存量"类 ⇒ 若其中任一条修好了又坏回来,
   它会被读成"已知" ⇒ ★ 那一次真失败【不会被看见】
```

★ **而 `_retiring` 的注释自己说了这个方向的代价:**
> 「加入的风险是把**新造成的失败洗成已知的**;退场的风险是把一条**仍然红着**的红
>  说成好了,于是它下次再红时会被读成已知。」

⇒ ★★★ **两个方向都有代价,而它选的是"宁可留着"。**
